# 졸업전시 기본 레퍼런스 8종

사용자가 확정한 ‘학교 프로젝트룸 졸업전시’와 참고 대화 「일정 정리+논문 개조식」의 레퍼런스 → 디자인 속성 → 배치 요소 → 위치 연결을 기준으로 제작했다. 내장 image_gen으로 8종을 각각 생성한 참고 자료다. 실제 학교 공간 사진, 실측 도면, 현재 프로젝트의 결과 이미지가 아니다.

서비스의 3단계 ‘기본 레퍼런스에서 고르기’에 등록했다. 이미지를 고른 뒤 배치 대상과 가져올 내용(형태·디자인, 조명 분위기, 색·소재)을 직접 연결한다. 원하는 부분만 영역 선택할 수 있다. 자료 선택이 실제 배치나 시안 생성을 자동 수행하지 않는다. 각 배경의 벽·기둥·바닥·공간 구조와 이미지에서 추정한 크기를 현재 도면에 가져오지 않는다.

최종 과업지의 정답 위치를 새로 정의하지 않았다. 실험에서 지급할 이미지 ID와 과업 조건은 이 세트의 버전으로 고정하고, 참가자가 사진을 검색하는 시간 대신 연결·배치 작업을 수행하도록 사용할 수 있다. 기둥용 이미지는 선택 자료이며 학교 공간에 기존 기둥이 있다는 증거가 아니다. 부착 방식은 연출 참고이며 실제 시공 가능성의 검증 자료가 아니다.

원본 PNG 8장은 이 폴더에 보관했다. manifest.json에는 실제 프롬프트, 파일별 1254×1254 크기와 SHA-256, 웹 이미지·미리보기 경로가 있다. 서비스용 WebP는 public/sample/library/graduation-20261012에 있으며 원본 해상도를 유지한다. 384px 미리보기만 별도로 사용해 목록 로딩을 줄였다. originals.zip은 PNG 원본·manifest·이 안내를 함께 담은 지급용 묶음이다.
