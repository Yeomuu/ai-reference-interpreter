# UI 비율·중복 정리 검토 — 2026-10-05

## 범위

기존 4단계, 데이터와 편집 경로를 유지하며 화면의 패널 비율·반복 표시·중립색 사용을 정리했다. 신규 기능이나 이미지 모델 변경은 없다. 현재 배포의 1440×900 화면과 수정한 로컬 화면을 이 작업에서 직접 캡처했다. 아래 이미지는 현재 작업 폴더의 `tmp/`에 보관한 QA 자료이며 웹 배포 자료가 아니다. 로컬 개발 화면에는 사용자 제공 개발용 글꼴이 적용될 수 있으므로 글꼴 차이를 이번 변경으로 해석하지 않는다.

## 1. 공간·방향 설정 — 정상

공간 사진/도면 탭, 업로드, 보존 구조와 컨셉을 유지한다. 보조 설정 패널은 320→360px, 자료 패널은 1064→1024px이다. 도면 상태는 캔버스에 남기고 페이지 위쪽의 중복 배지/revision은 생략했다. 기호·빗금 의미·조작 방법은 하단 한 메뉴에 모았다.

![수정 전 공간 도면](../tmp/ui-before-01-space-plan.png)
![수정 후 공간 도면](../tmp/ui-after-01-space-plan.png)

## 2. 레이아웃 구성 — 정상

왼쪽 도구/도면/우측 설정의 3열을 유지한다. 1440px에서 우측 속성은 260→약 317px, 가운데 도면은 888→약 831px이다. 선택 이름은 편집 입력란에 한 번 표시한다. 크기·회전·위치 고정·삭제와 수치 대안은 유지한다. 구조/영역의 그리기·검사 및 Undo/Redo는 동일하다.

![수정 전 레이아웃](../tmp/ui-before-02-placement.png)
![수정 후 레이아웃](../tmp/ui-after-02-placement.png)

## 3. 레퍼런스 적용 — 정상

레퍼런스/매핑 현황의 2열을 유지한다. 레퍼런스 패널은 320→360px이다. 선택 상태와 드래그 적용 안내는 하단 CTA 주변에서 한 번 설명한다. 전체 이미지/크롭, Shift 다중 선택, 드롭, 연결 내용 변경, 12장 legacy 자료 보존과 목록 복구를 확인했다. 탭은 중립색, 실제 이미지/대상 선택은 기존 선택색으로 구분한다.

![수정 전 레퍼런스](../tmp/ui-before-03-references.png)
![수정 후 레퍼런스](../tmp/ui-after-03-references.png)

## 4. 시안 생성 — 정상, 모델 품질은 검사 범위 밖

조건 패널은 400→440px이다. 미리보기 시점은 위 카메라 요약에서 선택하고 여러 생성 시점은 오른쪽 체크 목록에서 지정한다. 같은 상태를 바꾸던 별도 미리보기 드롭다운을 정리했다. 결과/생성 전 확인은 기존 4단계 내부 탭으로 이동한다. 시점 편집의 반복 조작 안내는 도면 안내 메뉴에 모았다. 실제 이미지 API는 모의 응답으로 결과 보관·stale·부분 수정만 검사했다.

![수정 전 생성 전 확인](../tmp/ui-before-04-review.png)
![수정 후 생성 전 확인](../tmp/ui-after-04-review.png)

## 디자인 적용

- 기존 토큰: 패널 r12, 버튼/입력/탭 r8, 이미지 r4, 기본 테두리 1px, 이미지 선택 테두리 2px.
- 패널 그림자는 생략한다. 탭과 표시 켜짐에는 중립색을 사용한다. 현재 단계·물체/대상 선택·키보드 초점은 기존 보라색으로 구분한다.
- 일반 Nucleo UI 아이콘과 PlanSymbol/LayoutSymbol의 구분을 유지한다. 미선택 조명 기호만 다른 물체와 같은 중립 선색으로 맞췄다.

## 검증 결과와 한계

- 28개 파일/237개 자동 테스트, ESLint, 앱/API TypeScript, production build 통과.
- 기존 `scripts/qa-workspace.mjs`: 영역/천장/상품 지지대, 크롭/드롭/연결 변경, 보존/잘못된 위치 거부, 이동 Undo/Redo/reload, 모의 생성/결과/부분 수정/stale/history, 삭제 복구, 초과 과거 이미지 목록 통과.
- 1575×884, 1440×900, 1280×720, 1101×884, 1070×671의 20개 화면에서 문서 넘침 없음, 안내 메뉴의 창 내부 배치·가로 넘침 없음·조작 설명, Escape/초점 복귀, 단계/URL/키보드/뒤로/앞으로/reload/로고 이동 통과.
- 생성 요청과 이미지 결과는 모의 응답으로 검사했다. 실제 유료 호출은 0회이며 새 모델 이미지의 정확도를 검증하지 않았다. 전체 스크린 리더/WCAG 인증이나 모바일 개편은 수행하지 않았다.
- 확인한 범위에서 새 차단 오류는 없었다. 기존 >500kB JS 묶음 경고는 남아 있다.
