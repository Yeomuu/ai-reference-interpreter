# 도면·배치·일일 한도·여러 시점 QA · 2026-09-29

## 범위와 결과

브라우저 검증은 별도의 Chrome 프로필과 샘플 데이터에서 실행했다. 이미지 생성 POST는 모의 JPEG 응답으로 가로채 실제 유료 모델 호출은 **0회**다. 따라서 실제 모델의 성공 응답이나 생성 결과의 시각적 정확도를 검증했다고 주장하지 않는다. 서버 한도 테스트는 공유 CAS 저장소 모형에서 경쟁 요청·재실행·실패·자정 경계·기존 ledger 변환을 검사했다.

## 사용자 동작 확인

- **도면:** 세로 업로드의 실제 비율, 기존 사각 구조/위치의 강제 덮어쓰기 제거, 기존 표시를 유지하는 명시적 옵션, 도면 교체 복구, 오목한 6점 윤곽 저장·새로고침, 연속 그리기 탭 유지. 수직 벽 그리기와 해제된 벽의 수직 교정, 사용자 지정 원형 기둥 크기를 확인했다.
- **물리적 충돌:** 실제 바닥/동선 윤곽의 내부로 검사한다. 오목한 동선의 바깥 빈 부분까지 막던 문제를 수정했다. 문·기둥 충돌은 생성 순서가 반대여도 거부한다. 상품은 연결 진열대와 겹칠 수 있고 진열대 이동·회전 시 상대 위치를 따른다.
- **참고 이미지:** 선택한 출처의 요소만 표시, 선택 요소 맨 위, 디자인 요소 제목 sticky. 제품 업로드의 진열 상품 기본 유형, 명시적 기본 진열대 추가/연결, 도면에서 다른 진열대 연결, 이미지 삭제/지속 복구를 확인했다. 10개 출처를 모두 모아 한 시점에 한 요청으로 전달했다.
- **Keep:** 실제 이름과 공식 잠금 아이콘의 포인터/키보드 전환. 필수 보존 벽의 탈착식 그래픽을 매번 확인하지 않고 이동하며 연결 모서리를 넘어 인접한 보존 벽에 붙일 수 있다. 구조 제거·이동·개구부/통로 충돌 검사는 유지한다.
- **복구:** 카메라 삭제, 주 시점 대체, 이전 이미지 보관, Ctrl+Z / Ctrl+Shift+Z로 카메라·배치 복구/다시 실행. 입력 필드의 기본 편집 단축키를 가로채지 않는다.
- **생성:** 3개 시점 선택은 고유 요청 3개·결과 3개이며 전체 배치 동안 버튼과 시점 선택이 잠긴다. 개인/서비스 잔여 횟수도 각각 3회 감소한다. 두 번째 요청이 실패하면 첫 번째 결과를 유지하고 세 번째 요청을 보내지 않는다. 유료 호출 자동 재시도는 없다.
- **화면:** 1440×900 / 1280×800 / 1113×697 / 768×900 / 390×844에서 7개 경로의 문서 스크롤·가로 넘침이 없다. 필요한 패널/작업 영역 내부만 스크롤한다. 오류·저장 안내·삭제 복구 알림이 캔버스 크기를 바꾸지 않는다. 오류 닫기, 상태 안내, 좁은 화면의 키보드 접근, 이미지 영역 선택 비율을 확인했다.
- **라우팅/실험:** 브라우저 이전/다음·직접 경로·새로고침·프로젝트 간 이동. 동의 전 로그 없음, 동의 후 의미 있는 동작 저장/복구, 실험 완료·6개 설문·실제 ZIP 다운로드/독립 해제를 확인했다. 무료 텍스트 비교나 사람의 정확도 코딩·서버 연구 데이터 수집을 구현했다고 주장하지 않는다.

## QA에서 수정한 문제

1. 그리기 오른쪽에 관리/좌표 행이 누적되어 캔버스가 축소됨 → 왼쪽 도구의 독립 스크롤로 이동, 중복 제목/출처 안내는 그리기 중 접음. 세로 윤곽 저장 후 1440px 화면에서 도면 높이 280px 이상을 검증했다.
2. 저장 후 제스처 안내가 캔버스를 밀어냄 → 캔버스 안 absolute status, 클릭 통과.
3. 충돌 안내가 남아 도면을 가림 → 도면 안내 닫기 제공, 저장 데이터/캔버스 경계 불변 검증.
4. 오목한 동선의 경계 사각형으로 충돌을 계산함 → 실제 polygon 내부와 선/원/사각 footprint 교차 검사.
5. 상품 이동 브라우저 검사의 렌더링 대기와 선택 이름표 영향 → 실제 상품 사각 marker 위치가 이동한 뒤 비교. 도메인 검사와 실제 도면의 이동 둘 다 통과했다.

## 한도·자료 처리 계약

- 서비스 전체 **하루 60회**, 서명된 익명 브라우저 **하루 20회**. 한국 시간 자정에 서버 날짜 기준으로 다음 날 횟수가 열린다. 배포/실패/상태 조회로 횟수를 초기화하지 않는다.
- 기존 private Blob `generation-quota/v1.json` 경로와 예약 UUID를 유지한다. 이전 UUID와 일별 immutable claim은 다음 날에도 재사용할 수 없다. 모델 호출 전에 예약하며 저장소 장애 시 호출하지 않는다.
- Production·Preview에 서버 전용 `GENERATION_IDENTITY_SECRET`을 설정했다. API 키/쿠키 값은 클라이언트 또는 연구 ZIP에 넣지 않는다. 쿠키는 HttpOnly·SameSite=Strict·프로덕션 Secure이다.
- 익명 브라우저는 실제 개인 계정이 아니다. 다른 기기/브라우저와 쿠키 삭제 후 동일인을 식별하지 못한다. 이 범위는 사용자가 승인했다.
- 적용 레퍼런스의 개수 제한은 없다. 전송 이미지는 최대 3개 모음 슬롯으로 묶으며 출처·crop manifest를 검사한다. 파일/요청 용량과 한 출처의 영역 수 등 기술적 한계는 남는다.
- 일반 편집 undo는 현재 탭의 50단계이며 새로고침 후 사라진다. 삭제 복구는 기존 영속 복구 기능을 유지한다. 이전 결과와 조건 출처를 덮어쓰거나 삭제하지 않는다.
- 도면 자동 실측/자동 추출이나 3D/CAD를 구현하지 않았다. 곡선은 사용자가 찍는 점으로 근사하며 개략 도면은 치수가 미확인임을 표시한다.
