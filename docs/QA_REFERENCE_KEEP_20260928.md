# 레퍼런스 삭제·필수 보존 전환과 기획 대조 · 2026-09-28

## 검토 근거

사용자가 제공한 **염예빈-2026 가을 학술대회 아이디어 정리 및 디벨롭.pdf**의 3쪽 전체 텍스트와 렌더링을 읽었습니다. 원본 Google 문서의 지정 탭은 일반 웹 도구에서 접근되지 않았고, 사용자가 PDF로 제공한 뒤 이 자료를 기준으로 대조했습니다. 원본 탭의 전체 내용과 PDF의 동일성을 별도로 검증했다고 주장하지 않습니다. PDF에는 17–20절이 없으므로 이전 PRODUCT 문서가 그 절들을 최우선으로 단정하던 문구도 수정했습니다.

| PDF의 핵심 | 구현과 검토 결과 |
| --- | --- |
| 1쪽: 기존 공간 조건과 여러 레퍼런스의 적용 요소·위치를 시각적으로 지정 | 공간 사진·도면·분위기·요소·제품 역할을 분리하고, 배치는 도면에서 유지합니다. 사진이나 참고 이미지로 치수를 추정하지 않습니다. |
| 2쪽 ①: 사용자가 유지할 벽·창·출입구·기둥 등을 Keep으로 지정 | 기본 보존을 켜 둔 구조도 사용자가 명시적으로 끄고 다시 켤 수 있습니다. 일괄 잠금이 사용자 선택을 막던 부분을 수정했습니다. |
| 2쪽 ②–③: 직접 요소를 선택하고 Reference → Element → Location을 확인·수정 | 이미지 영역 선택과 유형별 배치를 유지하고, 요소에서 원본 레퍼런스로 돌아가는 버튼을 추가했습니다. 이미지 삭제 시 연결된 요소를 함께 정리합니다. |
| 2쪽 ④, 3쪽: 시점 설정, 조건을 종합한 생성과 필요한 조건의 수정 | 카메라는 시점 단계에서만 표시합니다. 삭제·보존·위치 변경은 기존 결과를 보관하고 이전 조건으로 표시합니다. 삭제된 과거 요소가 다른 현재 요소의 편집으로 연결되던 문제를 차단했습니다. |
| 3쪽: 2~3개 참고 이미지로 공간 연출 예시 | 여러 이미지를 분리해서 사용하는 흐름을 유지합니다. 예시의 붉은 조명은 특정 색을 강제하는 조건으로 해석하지 않았으며 사용자 조건에서 변경할 수 있습니다. |

PDF의 예시 화면에 3D가 있다는 이유로 3D 편집기나 측량·CAD 기능을 추가하지 않았습니다. 이번 변경은 기존 작업의 삭제, 복구, 보존 선택과 위치 수정에 한정합니다. 유료 모델의 공간 일치 성능이나 실제 시공 가능성을 이 검토로 입증하지 않습니다.

## 고친 기능과 마이크로 인터랙션

- **레퍼런스 삭제:** 선택한 이미지 상단의 `이미지 삭제` → 이미지 이름·연결 요소 개수 확인 → 취소/삭제. 취소에 초점을 두고 Escape로 닫습니다. 마지막 이미지를 삭제해도 업로드와 빈 상태가 남습니다.
- **되돌리기:** 삭제 안내의 `삭제 되돌리기`는 3초 후 사라지는 성공 알림과 별도로 유지합니다. 다음 성공한 편집이나 안내 닫기 전까지 복구할 수 있습니다. 되돌린 레퍼런스/구조로 초점을 돌립니다. 결과나 카메라를 과거로 되돌리지 않습니다.
- **요소 관리:** 개별 요소 삭제는 원본 레퍼런스를 유지하고 추출 연결만 정리합니다. `제외`는 계속 보관하는 조건이며 삭제와 구별합니다. `원본 레퍼런스 보기`로 출처를 직접 확인합니다.
- **필수 보존:** 모든 구조의 `필수 보존 (위치 고정)` 스위치가 Keep과 배치 속성에 있습니다. 끄면 Keep과 잠금이 함께 해제되고, 켜면 위치·삭제가 잠깁니다. 설명·표면 허용 조건은 기억합니다. 새로고침/샘플 마이그레이션이 사용자의 명시적 해제를 덮어쓰지 않습니다.
- **구조 이동:** 기둥·벽·개구부·기존 천장 조명도 보존 해제 후 캔버스에서 이동합니다. 크기·방향·잡은 지점을 유지하고 방향키 대안을 제공합니다. 창·문은 연결 벽을 따라 이동합니다. 벽에 붙은 구조 중 잠긴 것이 있으면 그 이름과 다음 행동을 설명합니다.
- **충돌:** 새로 생기는 가구·벽·기둥·개구부·여닫이 공간·동선·카메라 충돌은 거부하고 이전 위치를 유지합니다. 구조 수치 입력의 빈 값·범위 오류도 이전 표시로 복원합니다. 기본 구조를 잠금 해제했다고 가벽으로 재분류하지 않습니다.
- **화면:** 카드 버튼을 줄바꿈해 잘림을 고쳤고, 배치의 좌측 목록을 한 스크롤 영역으로 정리했습니다. 업로드 중에는 등록 상태를 표시하고 추가 등록을 막습니다. 이동 가능한 이름표는 벽과 개구부 사이에 간격을 둡니다.
- **이력·원본:** 삭제 전 조건 스냅샷에 출처 메타데이터를 보관합니다. 현재 작업·저장된 결과·되돌리기에서 사용하는 이미지 원본은 유지하고, 사용하지 않는 삭제 원본은 되돌리기 종료 후 정리합니다.
- **생성 계약:** 켜진 보존과 해제된 구조를 구분해 저장된 도면 위치를 전달합니다. 해제된 구조를 자동으로 보존하라는 기존의 일괄 문장을 제거했습니다. 요청 중복 보호는 유지합니다.
