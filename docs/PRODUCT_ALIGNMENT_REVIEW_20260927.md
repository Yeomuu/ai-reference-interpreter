## 실험에 필요한 부분과 선택 기능

이 서비스의 최소 실험 경로는 **사진/도면 출처 확인 → Keep → 레퍼런스 전체·부분 선택 → 유형 지정 → 도면 위치 → 시점 → 조건 검토 → 출처가 명확한 결과 확인·부분 수정**이다. 직접 그리기와 참조 범위 선택은 이 경로의 누락이었으므로 보완했다.

결과 이력, 승인 이미지 모아보기, 추가 시점, 개별 내보내기는 앞선 사용자 요청 및 [PRODUCT.md](PRODUCT.md)의 선택 단계에 근거가 있다. 첫 번째 콘셉트를 만드는 데 필수로 요구하지 않으며 결과 화면에 둔다. 여러 시점 ZIP, 완성형 콜라주 편집기, 자동 도면 인식, 거리뷰, 실측 치수 추론은 핵심 실험에 필요하지 않고 현재 구현도 제공하지 않는다. 프로젝트 이름·유형·콘셉트 수정은 저장된 작업을 식별하고 정정하기 위한 최소 정보로 유지한다.

## 남은 한계와 후속 검증

- 손으로 그린 개략 도면의 사각형 영역과 출입 여유 검사는 실측 안전 판정이 아니다. 실제 시공·피난·접근성 판단에 사용하면 안 된다.
- 필수 보존 구조를 잘못 표시했을 때 일반 편집에서 이동/삭제할 수 없다. 이는 현재 Keep 규칙을 지키는 대신 정정 흐름이 부족한 상태다. 실험 참여자의 오입력 빈도를 관찰하고, 확정 전 임시 초안 또는 명시적인 원본 자료 정정 절차를 별도 설계해야 한다.
- 이미지 모델은 Keep·배치·다중 시점 일관성을 보장하지 않는다. 첫 실제 생성 시 출력 이미지와 저장된 조건의 일치 여부를 사람이 검토해야 한다.
- 2026-09-27에 실행한 로컬 도면/레퍼런스 제스처 점검과 390·1280·1440px 가시성 확인은 [QA_UI_AUDIT_20260927.md](QA_UI_AUDIT_20260927.md)에 기록했다. 배포된 API 상태는 최신 배포 뒤 과금 없는 GET으로 다시 검증한다.
