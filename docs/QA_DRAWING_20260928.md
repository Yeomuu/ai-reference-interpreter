# 구조·영역·동선 편집 QA · 2026-09-28

## 수정한 동작

- 연결 벽은 도면의 이름표와 강조선으로 확인하고, 이름 또는 벽 선을 눌러 선택합니다. 창·문·출입구는 벽 근처에서 시작해 끌면 같은 벽 선에 맞춰 저장됩니다.
- 선택/가벽 이동과 그리기 모드를 구분합니다. 이동 가능한 가벽만 점선·이름표와 목록으로 표시하며, 가벽이 없는 도면은 빈 공간 드래그가 이동 기능처럼 보이지 않도록 설명합니다.
- 그리기 중에는 사진을 접어 도면과 도구를 넓힙니다. 저장 후 선택 모드로 돌아갑니다. 구조/영역 표시를 거부하면 저장된 도면을 유지하고 이유를 캔버스 위에 표시합니다.
- 같은 물리 층의 물체 점유, 중복 구조·개구부·동일 영역, 구조나 바닥 물체를 가로지르는 새 동선을 거부합니다. 바닥·천장·분위기 범위의 정상적인 중첩은 허용합니다.

## 실제 화면·제스처 검증

Codex 화면 조작 런타임은 `setup refresh had errors`로 두 번 실패했습니다. 사용자 로그인 브라우저와 분리한 Chrome 헤드리스 세션에서 로컬 Vite `127.0.0.1:5174`를 검증했습니다. 모든 `/api/` 경로를 테스트에서 가로채 실제 유료 요청을 차단했습니다. 원본 사용자 저장 데이터·자격 증명은 사용하지 않았습니다.

- 가벽 없는 상태의 안내, 유효 가벽 선 그리기, 저장 후 선택 복귀: 통과.
- 가벽 이름표 드래그·방향키 이동, 길이 보존 및 잡은 위치의 오프셋 유지: 통과.
- 중복 가벽·기둥·창과 동일 분위기 영역 거부, 이전 도면 유지: 통과.
- 도면 이름표로 오른쪽 벽 선택, 벽에서 8 CSS px 떨어진 시작점을 선에 맞춰 창 그리기: 통과.
- 벽 바깥 클릭 안내와 진열대를 가로지르는 동선 거부: 통과.
- 별도 천장 범위와 바닥의 유효한 중첩, 점 클릭으로 기둥 추가: 통과.
- Esc로 진행 중인 선 취소, 드래그 중 키보드로 구조 도구 변경 후 잔여 제스처 취소: 통과. 이 과정에서 드래그 시작 시 캔버스에 키보드 초점을 두도록 수정했습니다.

- 페이지 JavaScript 오류 0건, 유료 API 호출 0건.

검증 스크립트·보고서·스크린샷은 Git에서 제외되는 `qa-screens/drawing-qa.mjs`, `drawing-report.json`, `drawing-1280.png`, `drawing-900.png`, `drawing-390.png`에 보관됩니다.

- `npm run lint`, `npm run typecheck`, `npm run build`: 통과.
- `npm test`: 10개 파일, 80개 테스트 통과. 구조/영역·같은 층 점유 검증 14개와 벽 투영·스냅 및 캔버스 표시 검증을 추가했습니다.
- 기존 부분 레퍼런스 API 테스트의 추가 진열대는 중복 점유를 피한 위치로 바꿨습니다. API 메타데이터/전송 순서와 모의 제공자 검증 의도 및 실제 겹침 제한은 유지했습니다.

## 범위와 한계

- 점유·충돌 검사는 정규화 개략 도면의 2D 검사입니다. 층별 물리 모델이나 실측 안전 검사로 해석하지 않습니다.
- 천장 물체에는 정확한 크기 필드가 없으므로 선택 천장 영역 전체를 점유합니다. 여러 개를 놓으려면 서로 겹치지 않는 작은 영역을 지정해야 합니다.
- 모바일 레이아웃과 마우스/키보드 제스처를 확인했으며 실제 터치 기기 검증은 하지 않았습니다.
- 이번 QA는 이미지 생성 품질·모델 계정 권한을 검증하지 않았고 과금 호출도 하지 않았습니다.
