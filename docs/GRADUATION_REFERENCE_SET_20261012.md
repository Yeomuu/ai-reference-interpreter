# 졸업전시 레퍼런스 세트

사용자가 학교 프로젝트룸 졸업전시를 기준으로 선택해 새 AI 참고 이미지 8종을 제작했다. 참고 대화에서 확인한 시스템 개요의 선택적 속성 연결을 따르며 공식 과업지나 정답 좌표를 임의로 만들지 않았다.

전시대 2종, 테이블 1종, 의자 1종, 벽/기둥 패널 2종, 벽/천장 조명 2종. 배경을 단순하게 만들고 물체의 전체 형태와 소재를 식별할 수 있게 했다. 이미지의 실제 형상·텍스트 없음·잘림·대상 구분을 직접 확인했다. 모두 1254×1254이고 원본 PNG와 실제 프롬프트를 output/imagegen/graduation-20261012에 보관한다.

새 8종과 기존 6장을 서비스의 동일 기본 자료 목록에서 제공한다. 전시대·테이블·벽면·의자·조명으로 분류한다. 신규 원본 WebP 8장의 합계 약 1.05MB, 미리보기 8장 합계 약 40KB. 기존 URI/출처/등록 ID를 보존하고 자동 등록·자동 연결은 하지 않는다. 현재 프로젝트 8장 한도, 레퍼런스 삭제 복구, 이력과 생성 입력 계약은 유지한다.

실험에서는 지급할 이미지 ID와 과업 조건을 확정해 사용한다. 기둥용 패널은 선택 참고이며 기존 학교 공간 구조를 추가로 증명하지 않는다. 새 폴더 README의 요소별 연결표와 manifest의 프롬프트가 제공 자료의 근거다.

웹·참가자 PDF 가이드의 자료 개수와 분류를 갱신하고, 테이블 벽 밀착 및 기둥 면 지정 안내를 보완했다. 가이드 생성 템플릿의 로고 경로도 최신 파일로 정리했다. 진행자 문서의 과업 초안/답안 기준을 참가자 가이드에 넣지 않았다.

## 검증
격리 Edge에서 14장 전부 로딩, 새 8종 미리보기, 테이블 필터, 등록 시 기존 배치 보존, 중복 등록 슬롯 유지, 전시대 연결과 reload, 1440/938/390 캡처·가로 넘침·JS 오류 없음 확인. PDF10페이지의 변경된5·6페이지를 렌더링해 직접 확인했다. PNG8장+manifest+README의 ZIP10파일을 검사했다. 새 원본8장은 내장 image_gen으로 실제 생성했으며 서비스 /api/generate를 통한 유료 QA 호출은 0회다.
