# 오프라인 데모 이미지 기록

`public/sample/`의 다섯 PNG 파일은 앱 개발 중 Codex 내장 이미지 생성 도구로 준비한 설명용 자료입니다. 앱 실행 중 생성한 이미지가 아니며 사용자 조건·추가 시점을 반영한 산출물로 취급하지 않습니다. 평면도와 치수의 근거로도 사용하지 않습니다.

| 파일 | 제작 요청의 핵심 내용 |
|---|---|
| `existing-space.png` | 입구에서 바라본 비어 있는 직사각형 코스메틱 팝업 공간. 후면 창, 왼쪽 기둥, 밝은 바닥을 보여주는 현장 참고 사진. |
| `atmosphere.png` | 크림색 벽과 바닥에 따뜻한 간접 조명이 퍼지는 쇼룸 분위기 참고. |
| `product.png` | 배경과 분리해 찍은 낮은 곡선형 아이보리 화장품 진열대 제품 참고. |
| `graphic.png` | 아이보리·샌드·토프 곡선이 겹친 탈착식 벽면 포토존 패널 참고. |
| `result.png` | `existing-space.png`를 편집 대상으로 사용해 원래 창·기둥·시점을 유지하면서 중앙 진열대, 간접 조명, 후면 탈착식 그래픽을 추가한 고정 데모 이미지. |

모든 요청에는 사람·로고·텍스트·워터마크를 넣지 말라는 조건을 주었습니다. 결과 이미지는 공간 일관성이나 시공 가능성을 검증한 자료가 아닙니다.
