- 기존 가이드 219:1462를 v1.4.2로 갱신. 원본 이미지, 6초/14px 부유와 작은 포인터 이동의 구분, 수정 가능한 기본값, 핵심 작업 우선 원칙을 기록.

웹은 사용자 제공 Wanted Sans / Adobe timeline-210, Figma는 사용자가 승인한 Noto Sans KR 대체 글꼴이다. 글꼴의 실제 폭 차이 때문에 두 렌더링을 글자 단위로 동일하다고 주장하지 않는다. 로고는 기존 원본 벡터다. 네이티브 텍스트·컴포넌트·도면을 유지했으며 전체 UI를 이미지로 붙이지 않았다. API나 라이브러리 publish는 추가하지 않았다. HIG 참고는 콘텐츠·분할 편집·상태·복구 원칙에 한정하며 원본 반경을 바꾸는 근거로 사용하지 않는다.
