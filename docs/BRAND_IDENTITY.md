## 방향

실제 공간에 배치와 참고 디자인을 연결해 공간을 다시 구성하는 서비스다. 심벌은 빈 공간을 품은 **R 프레임**에 두 면을 접어 공간의 구성을 바꾸는 모습을 나타낸다. 넓은 획·열린 여백·직선 형태를 사용해 작은 편집기 헤더에서도 윤곽이 남도록 한다. 이 의미는 이번 디자인 의도이며 사용자 조사로 검증된 인식 결과를 주장하지 않는다.

## 출처와 범위

- 색상 방향: 사용자가 첨부한 Lavender + Sage 이미지. 밝은 라벤더 `#B6AAC2`와 세이지 `#A6B38E`를 직접 지정한 기준으로 사용한다.
- [Branding Style Guides의 디자인 가이드 목록](https://brandingstyleguides.com/label/design/)과 [Floating Point Art의 소개](https://brandingstyleguides.com/guide/fpa-2026/)에서 정체성을 여러 적용 환경에 일관되게 사용하는 방식과 조립·변형의 방향을 참고했다. 로그인 뒤의 매뉴얼 전체를 읽었다고 주장하지 않는다. 타 브랜드의 로고·전용 서체·색상·도형은 가져오지 않았다.
- 심벌은 이 프로젝트를 위해 직접 만든 SVG다. 편집 액션의 Nucleo 아이콘이나 도면 기호를 대체하지 않는다.

## 자산

| 자산 | 용도 |
|---|---|
| `public/brand/mark.svg` | 앱·사용 가이드 헤더와 favicon의 컬러 심벌 |
| `public/brand/mark-mono.svg` | 단색 출력·단색 신원 표시에 사용할 동일 윤곽 |
| 실제 텍스트 `ReSpace` | 현재 UI 서체·700 굵기·-.025em 자간의 워드마크 |

심벌은 48×48 viewBox, 외곽 6~42 / 4~44 범위다. 앱에서는 기존 30×30 크기를 유지한다. 주 심벌은 짙은 중립색, 위 접힌 면은 라벤더, 아래 면은 세이지다. 색을 못 구분해도 R의 전체 윤곽과 서비스명이 남는다. 텍스트와 심벌 사이에는 기존 space-12를 사용하고, 설명은 ‘전시·팝업 공간 디자인’을 유지한다. 외곽에 최소 4px 여백을 확보한다. 작은 크기에서 워드마크 대신 심벌만 쓰는 경우는 favicon에 한정한다.

## 색의 역할

| 역할 | 토큰 | 적용 |

| 기본 표면 | neutral-white / neutral-50 | 흰 편집 패널과 옅은 중립 작업 배경 |
| 주 행동·읽기 | neutral-900 / neutral-600 | 이미지 생성·다음 단계·본문과 보조 설명 |
| 선택·포커스 | lavender-700 / lavender-500 / lavender-50 | 선택 텍스트·윤곽·포커스·연한 선택 배경 |

| 브랜드 면 | lavender-300 / sage-300 | 신원 심벌의 제한된 면 |
| 정보·문제 | 기존 blue/red 계열 | 창·통행 등 정보, 충돌·삭제 등 오류 의미 유지 |

모든 UI 색은 `src/styles/tokens.css`에서 관리한다. 오래된 violet/green 이름은 새 토큰을 참조하는 별칭이다. SVG는 독립 파일에서도 열리도록 고정 색을 포함하며 해당 값은 같은 토큰에서 대조한다. 밝은 라벤더·세이지는 작은 글자색으로 사용하지 않는다.

사진·도면·레퍼런스·생성 결과의 색과 종횡비를 바꾸지 않는다. crop 내부는 투명하며 바깥쪽만 어둡게 하여 선택 영역을 표시한다. 캔버스의 벽·가구·창·동선·분위기 기호와 오류 이유는 기존 의미를 유지한다. 상태는 색만으로 전달하지 않고 현재 아이콘·선·패턴·텍스트를 함께 유지한다. 새로운 화면이나 기능은 추가하지 않는다.
