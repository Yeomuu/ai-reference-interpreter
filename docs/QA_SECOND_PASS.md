# 후속 기술 QA · 2026-09-25

브라우저 주석 15개, 알림 동작, 로고 요청을 반영한 뒤 진행한 점검입니다. 앞선 시점의 기록인 [QA_FIRST_PASS.md](QA_FIRST_PASS.md)는 소급 수정하지 않았습니다. 사양을 바꾼 위치와 이유는 [UX_SPEC_CHANGELOG.md](UX_SPEC_CHANGELOG.md)에 있습니다.

## 자동 검사

| 명령 | 결과 |
|---|---|
| `npm run lint` | 통과 |
| `npm run typecheck` | 통과 |
| `npm test -- --run` | 2개 테스트 파일, 24개 테스트 통과 |
| `npm run build` | 통과. `dist/brand/mark.svg`와 파비콘 링크 포함 |

도메인 테스트는 필수 Keep 제거 거부, 선택형 가벽의 가구·기둥·출입구·동선·바닥 경계 충돌, 이후 가구 배치 및 사전 검토 충돌, 기존 조명 색감 제한, 사진 라벨 이동의 결과 버전 보존을 확인합니다.

## 브라우저 확인

- 1113px, 1280px, 1440px 데스크톱과 600px 좁은 화면에서 작업 화면을 확인했습니다. 측정한 문서 `scrollWidth`는 각 `clientWidth`와 같았고, 600px에서는 캔버스와 속성 패널이 세로로 배치되었습니다. 1280px에서는 두 사이드 패널과 중앙 캔버스가 동시에 보였습니다.
- 도면의 가구를 기둥으로 끌었을 때 충돌 오류가 표시되고 직전 유효 위치가 유지되었습니다. 벽 그래픽을 창 구간으로 끌었을 때 기존 벽 구간 68–90%가 유지되었습니다.
- 선택형 가벽을 추가하고 선 위에서 끌어 이동해 저장한 뒤 Keep을 지정하자 캔버스의 이동 안내가 사라지고 선택 전용으로 바뀌었습니다. Keep 해제 및 가벽 제거도 확인했습니다. 가구를 가로지르는 새 가벽 입력은 저장되지 않았습니다.
- 카메라 위치와 시선 방향을 캔버스에서 끌어 바꾼 뒤 목록·속성 입력에 같은 값이 표시되었습니다. 바닥 요소를 방향키로 옮긴 뒤 숫자 입력란도 새 위치를 표시했습니다.
- 사진, 결과 이력, 승인 이미지에서 버튼과 클릭 드래그로 이전·다음 항목으로 이동했습니다. 현재/전체 수가 바뀌고 하단 가로 스크롤바는 보이지 않았습니다.
- 성공 안내는 3초 뒤 투명해지기 시작해 약 3.5초에 제거되었고, X를 누르면 즉시 닫혔습니다. 검증 오류는 3초가 지나거나 작업 단계를 바꾸어도 유지되며 X 또는 해결 동작으로 닫힙니다.
- 개발 서버 브라우저 로그에서 런타임 오류는 확인되지 않았습니다. 헤더의 새 브랜드 SVG가 렌더링되고 `index.html`은 같은 SVG를 파비콘으로 가리킵니다.

## 범위와 남은 외부 의존성

이미지 생성 API가 없어 결과는 명시된 오프라인 데모 샘플입니다. 샘플 이미지는 현재 조건을 반영해 생성된 결과가 아닙니다. 공식 Nucleo UI Essential Outline SVG의 확인 가능한 원본이 없어 조작부는 텍스트를 사용합니다. 자체 제작 브랜드 마크는 UI 아이콘 세트를 대신하지 않습니다. Paperlogy 원본 및 라이선스 확인은 [FONT_PROVENANCE.md](FONT_PROVENANCE.md)에 있습니다.
