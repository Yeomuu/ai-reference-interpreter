# 벽 밀착·기둥 부착 변경 및 확인

사용자 확인: 테이블은 바닥에 놓인 테이블을 벽에 밀착한다.

## 동작
- 테이블은 floor-point를 유지한다. 실제 회전 윤곽이 벽 선에 닿는 것은 허용하고 벽을 관통하는 것은 거부한다. 다른 바닥 물체의 충돌 기준은 유지한다.
- 오른쪽 설정에서 벽을 골라 ‘벽에 붙여 놓기’를 누르면 벽과 나란히 회전하고 밀착한다. 가까운 벽으로 클릭·드래그·방향키 이동 시 한 격자 셀 안에서 밀착하고 Alt로 해제한다. 너무 짧은 벽은 안내하며 저장하지 않는다.
- 창·문·출입구, 여닫이 공간, 통로, 기둥, 다른 가구 충돌은 계속 검사한다. 상품/받침 연결은 유지한다. 테이블은 벽과 영구 연결되지 않는다.
- 그래픽·벽 조명은 기존 벽, 가벽 A/B 면, 사각 기둥 네 면, 원형 기둥 둘레에 부착한다. 기둥을 클릭하면 가까운 면을 선택한 초안이 열리며 면·폭을 확인해 적용한다. 원형은 도면 위쪽 12시 방향 0%부터 시계 방향의 0–100% 구간이다. 경계를 넘는 구간은 나누어 등록한다.
- 호스트의 보존 잠금은 유지한다. 탈착식 그래픽은 허용하고 보존 소재 교체는 거부하며 조명의 고정 방식 경고는 유지한다. 부착 모드에서 기둥이 끌려 이동하지 않는다.
- 실제 호스트 ID와 선택 면을 기존 wall-segment의 optional pillarFace로 저장한다. 기존 데이터/이력은 재작성하지 않는다. 도면, 참고 연결, 생성 가이드·프롬프트, 실험 로그가 같은 좌표를 사용한다. 숨긴 기둥 면의 부착물을 옮기거나 복제하지 않도록 모델에 지시한다.

## 실행 확인
- 자동 테스트: 다섯 벽 밀착, 관통 거부, 대각선 벽·다각형 바닥, 창/출입구·기둥·가구 충돌, 자동 밀착, 다른 물체 예외 금지, 기둥 다섯 면, 같은 면 겹침, 잘못된 면/유형, 보존·형태 변경, 참고 연결, 가이드/프롬프트/로그 좌표, 기존·손상 데이터 판별.
- 격리 Edge: 테이블 수동 밀착·끌기·Alt, undo/redo/reload, 사각 기둥 오른쪽 면 60% 폭과 끝점 방향키/undo, 원형 둘레, 가벽 A면, 3단계 매핑 대상, 1440×900/938×672 캡처와 가로 넘침 없음. 사용자 프로필·데이터는 수정하지 않았다.
- 캡처 직접 확인: 외부 QA 폴더 wall-attachments-20261012의 table-flush, pillar-face, round-pillar, partition-and-pillar, mapping 화면.
- 전체 자동 테스트 34파일 300개, lint, 앱/API 타입 검사, production build 확인. 최종 수와 배포는 아래 기록에 확정한다.

실제 유료 호출 0회. 생성 조건 전달을 확인했으며 실제 모델 결과, 공법/하중/실측 정확도는 재검증하지 않았다. 기둥 면 이름은 도면 방향이며 지리적 방위가 아니다. 수정 전 Git 복구 지점을 보존한다.
