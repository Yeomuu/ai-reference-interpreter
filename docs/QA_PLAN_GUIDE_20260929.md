# 도면 가시성·생성 입력 검증 · 2026-09-29

## 검증 범위

- 167개 단위 테스트/20개 파일, lint, 타입 검사와 프로덕션 빌드 통과. 빌드의 단일 JS 청크는 500KB 권고를 넘으며 압축 전 크기 경고가 남는다(빌드 오류 아님).
- 새 단위 검증: 세로/다각형 도면, 회전 진열대 위 상품, 업로드 배경 누락/외부 URL 거절, 사용자 텍스트 escape, manifest 수정 버전/시점, 조명/팔레트 전이 분리, API의 가이드 누락/불일치 quota 예약 전 거절.
- 실제 클라이언트의 JPEG 가이드 준비 및 모의 POST 7항목: 기존 사진+가이드+3 참고 입력, JPEG 픽셀과 용량, 모달 없는 대조, 현재 위치 변경/카메라 삭제 뒤 과거 도면 동일, 1070/390 viewport, 업로드 배경의 세로 비율, runtime 오류 0.
- 주요 편집 14항목: 시점 삭제/되돌리기, 여러 시점 및 부분 실패 보존, Keep 벽 장식 이동/모서리 벽 전환, absolute 충돌 안내, 레퍼런스 삭제/지속 undo, 10개 레퍼런스 모음, 1440/1070/390 전체 단계.
- 여러 시점 큐 7항목: 처리 중 무료 상태 대기 후 2·3번 시점 각 1회, 고유 UUID, 정확한 3회 차감, 한도/상태 오류/지속 처리 중/불확실 응답의 후속 POST 차단 및 첫 이미지 보존.
- 이동 가시성 13항목: 네 캔버스 모드의 동선/여닫이/물체 점유, 레이어 숨김 시 최소 제한, 실제 pointer 미리보기/거절·정상 저장, 이름표가 제한 범위를 가리지 않음, 관련 시점만 읽기 전용 표시, 작은 화면/외부 스크롤 0.
- 영역 매핑 QA는 새 기본 표시(천장/공간 기본 숨김)를 반영해 공간 레이어를 직접 켠 뒤 다른 영역 약화/이름표 겹침/키보드 표시 설정을 검사한다. 이름표의 시각 면과 투명 hit rect는 같은 항목이므로 hit rect 하나를 기준으로 겹침을 검사한다.

## 실제 모델 테스트와 배포

사용자가 샘플 조건 1장의 유료 실행을 승인했다. 위 검증은 모의 POST 및 로컬 렌더링이며 아직 실제 모델 결과의 품질을 의미하지 않는다. 배포/실제 호출의 확인 결과는 완료 후 아래에 추가한다. 테스트 요청은 중복 전송/자동 재시도를 차단하고 기존 이미지·일일 한도 기록을 보존한다.

## 구현상 한계

- 이미지 모델의 완전한 위치/형태/치수 일치를 보장하지 않는다. 새 가이드는 입력 안내이며 결과를 검증하는 CAD/3D 시스템이 아니다.
- guide manifest는 클라이언트가 선언한 저장 조건을 검증한다. 이미지 픽셀의 진위 증명이나 사람의 정확도 평가가 아니다.
- 모든 기존 결과/사용자 조건을 유지한다. 새 샘플 조명 조건만 중립 마감+온백색 빛으로 명확히 한다. 오래된 사용자 조건을 자동 수정하지 않는다.
- 개략 도면 입력 한 장이 추가되어 입력 토큰 비용은 늘 수 있다. 모델/low/n=1/한도는 유지하며 추가 모델 분석/변형 호출은 없다.
