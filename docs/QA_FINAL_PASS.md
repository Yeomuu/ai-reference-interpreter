## 기능 확인

- 깨끗한 저장 상태에서 AURA POP-UP 샘플의 사전 검토가 통과했고, `새 데모 미리보기 기록 열기`가 별도 버전 기록을 만들었다. 결과 화면은 사전 제공 샘플이며 현재 설정을 반영한 생성 이미지가 아님을 표시한다.
- 버전 1·2를 각각 승인하고 이력·승인 갤러리의 `1 / 2`, `2 / 2` 표기, 이전·다음 버튼과 방향키 탐색을 확인했다. 승인 갤러리는 현재 이미지를 중앙에 두고 존재하는 이웃 이미지의 가장자리만 보여 준다.
- 390px 도면에서 카메라 본체를 끌어 위치를 `50%, 79%`에서 `56%, 79%`로 옮겼다. 별도 회전 손잡이를 끌어 방향만 `270°`에서 `292°`로 바꾸고 위치가 유지됨을 확인했다. 추가 카메라는 유효한 바닥 `32%, 70%`에 생성됐다. 기존 저장 자료의 도면 밖 카메라는 속성 패널에 지속 경고를 표시했다.
- 보존 구조의 문 개구부와 벽 그래픽이 겹치는 자료에서는 사전 검토가 미리보기를 막고 해당 배치 요소로 이동했다. 벽 그래픽 구간만 `68–90%`에서 `63–70%`로 바꾼 뒤 검토가 통과했고, 진열대·조명·제외 요소와 이전 샘플 결과는 유지되며 이전 결과에 `이전 조건`이 붙었다.
- 768px에서 도면은 전체 너비로 먼저 표시되고 목록·속성 패널은 다음 행에 겹치지 않는다. 390px 결과의 현재 단계 `07 결과`가 탐색 막대에 보인다. 측정한 화면 너비 390·768·1440px에서 본문 가로 넘침은 없었다.
- 새 단계 제목의 초점 이동, 선택 목록의 `aria-pressed`, 단일 항목 캐러셀의 불필요한 Tab 정지점 제거, 조작 경계 대비와 모바일 터치 영역을 코드 및 브라우저에서 확인했다. 강제 색상·투명도 감소에는 불투명 표면과 시스템 테두리·초점의 CSS 대체 규칙을 적용했다.

## 자동 검사와 산출물

`npm run lint`, `npm run typecheck`, `npm test`(33개 통과), `npm run build`가 모두 통과했다. 프로덕션 미리보기 첫 화면도 열어 확인했다. 빌드의 `dist/`에는 사용자 제공 Paperlogy TTF가 없으며, 개발 화면에서는 검증된 로컬 폰트를 읽는다. 프로덕션은 `Noto Sans KR` 또는 시스템 산세리프로 대체된다. 이미지 파일의 확장자·MIME·시그니처 검증, 저장 데이터 격리, Keep·카메라·가벽 충돌은 자동 테스트에 포함된다.

## 남은 외부 연동

이미지 생성 API 자격 증명이 없어 이미지 생성은 구현된 연동이 아니다. 결과는 사전 준비된 오프라인 데모 샘플이며 새로운 시점의 일관된 생성 이미지를 주장하지 않는다. 사용자가 올리는 Paperlogy TTF는 프로덕션 산출물에 포함하지 않는다. 파일 선택 대화상자를 통한 업로드는 이번 브라우저 제어에서 다시 실행하지 못했으며, 파일 검증 자동 테스트와 [앞선 1차 QA](QA_FIRST_PASS.md)의 업로드 기록으로 확인했다.
