# OpenAI 이미지 생성 연결

확인일: 2026-09-28. 아래 가격과 모델 지원 범위는 배포 후에도 [OpenAI 공식 모델·요금 안내](https://developers.openai.com/api/docs/models/gpt-image-1-mini)에서 다시 확인해야 한다.

## 동작 범위

- 무료 탐색, 도면 편집, 조건 검토, 사전 제공 샘플은 API를 호출하지 않는다.
- 사용자가 조건 검토에서 명시적으로 **AI 이미지 생성**을 실행할 때만 `POST /api/generate`가 호출된다. `GET /api/status`는 서버 설정 유무만 확인하며 생성 또는 과금을 하지 않는다.
- 서버는 `OPENAI_API_KEY`를 브라우저로 보내지 않는다. 비용 악용을 줄이기 위해 `GENERATION_ACCESS_CODE`가 설정되어야 하며, 사용자가 입력한 코드는 브라우저 저장소에 보관하지 않는다. 잘못된 코드, 잘못된 도면·배치·시점, 빠진 레퍼런스, 큰 입력은 OpenAI 호출 전에 거절한다.
- 사용자가 선택한 기존 공간 사진 1장, 업로드 도면 이미지가 있으면 그 1장, 적용된 레퍼런스 이미지 최대 3장을 각각 역할을 붙여 보낸다. 샘플 개략 도면은 사진에서 추론한 측량 도면으로 취급하지 않으며, 구조·배치·시점의 정규화 좌표를 문장 조건으로 전달한다. 실제 AI 결과에는 어떤 기존 사진을 입력했는지 기록한다.
- 브라우저는 전송 전 이미지를 JPEG로 축소한다. 레퍼런스의 적용 요소가 모두 부분 영역을 가리키면 원본의 해당 픽셀을 잘라 보낸다. 한 원본에서 서로 다른 부분 영역이 2~4개면 한 장의 격자 이미지에 합치고, 생성 지시문은 각 칸의 출처를 구분한다. 같은 원본의 적용 요소 중 전체 이미지를 참조하는 요소가 있으면 원본 전체를 보낸다. 서로 다른 부분 영역 5개 이상은 유료 요청 전에 거절한다. 서버는 이 준비 정보와 프로젝트의 저장 조건이 일치하는지 검증한다.
- 서버는 최대 5장, 장당 550 KB, 요청 본문 4 MB를 제한한다. 서버는 프로젝트와 배치 조건을 재검증한다.
- `vercel.json`은 생성 함수에 최대 180초를 배정한다. [Vercel 함수 실행 시간 안내](https://vercel.com/docs/functions/configuring-functions/duration)에 따르면 Hobby의 Fluid Compute가 켜진 경우 300초까지 가능하지만, 꺼진 Hobby 환경은 최대 60초이므로 배포 설정을 확인해야 한다. 요청·응답의 [4.5 MB 제한](https://vercel.com/docs/errors/function_response_payload_too_large) 때문에 입력 이미지와 결과 JPEG 크기를 제한한다.
- 생성 결과는 브라우저 IndexedDB에 저장하고 프로젝트 기록에는 `asset://` URI와 `origin: 'ai'`를 보관한다. 과거 결과를 덮어쓰지 않는다. 생성 응답을 확인했지만 프로젝트 기록 저장이 실패하면 현재 탭의 메모리에 결과를 표시하고 즉시 이미지 내보내기와 기록 저장 재시도를 제공한다. 저장 문제를 해결하기 전에는 추가 유료 요청을 막는다.
- 전송 뒤 네트워크가 끊기거나 성공 응답을 읽지 못하면 서버 작업과 과금 여부를 단정할 수 없다. 같은 페이지 세션에서 180초 동안 재시도를 막고, 이후에도 사용자가 결과 이력·사용량을 확인한 뒤 명시적으로 잠금을 풀어야 한다. 이는 동일 탭의 우발적 중복 호출 보호다. 여러 탭이나 직접 HTTP 재전송에 대한 전역 멱등성·사용량 상한은 공용 저장소가 없는 현재 실험 범위에 포함되지 않는다.

## 모델과 비용

현재 서버 설정은 `gpt-image-1-mini`, `quality=low`, `size=1536x1024`, `n=1`, `input_fidelity=low`, JPEG 출력이다. OpenAI의 [GPT-Image-1 Mini 공식 가격 표](https://developers.openai.com/api/docs/models/gpt-image-1-mini)는 낮은 품질의 1536×1024 출력 1장에 **$0.006** 예시를 제시한다. 이는 총 청구액이 아니다. 입력 문장은 $2/백만 토큰, 입력 이미지는 $2.50/백만 토큰의 별도 요금이 있으며 실제 비용은 입력 내용과 청구 시점 가격에 따라 달라진다. 모델 페이지는 무료 사용 등급에서 이미지 생성을 지원하지 않는다고 명시하므로, 프로젝트 결제 설정과 사용 한도도 별도로 확인해야 한다.

이 모델은 [OpenAI 공식 사용 종료 공지](https://developers.openai.com/api/docs/deprecations)에 따라 **2026-12-01 API 종료 예정**이다. 초기 비용 최소화를 위한 한시적인 선택이며, 그 전에 `gpt-image-2` 같은 지원 모델로 교체해야 한다. `gpt-image-2`는 낮은 품질의 가로 출력 예시가 $0.005이지만 입력 이미지 토큰은 $4/백만 토큰이고 입력 충실도를 낮출 수 없어, 여러 레퍼런스를 보내는 이 흐름의 총액이 반드시 더 저렴하다고 단정할 수 없다. 모델 이름·품질·크기 값은 공용 계약 파일 한곳에 모아 교체하도록 했다.

[공식 이미지 생성 안내](https://developers.openai.com/api/docs/guides/image-generation)는 이미지 편집 API가 여러 참조 사진을 입력받고 JPEG 출력을 지원한다고 설명한다. 같은 안내는 구조화된 구도에서 정확한 위치 재현에 한계가 있음을 명시한다. 따라서 이 서비스의 Keep·도면 검증은 생성 **전 입력 검증**이며, 생성 이미지가 그 제약을 완벽히 지켰다는 자동 판정이 아니다. 사용자가 결과를 직접 검토하고 승인해야 한다.

## 배포 설정과 검증 상태

Vercel 서버 환경 변수에 `OPENAI_API_KEY`와 별도의 48자 이상 `GENERATION_ACCESS_CODE`를 등록해야 실생성이 활성화된다. 짧은 이전 코드는 미설정 상태로 취급해 유료 호출을 차단한다. 저장소에는 `.env*`가 포함되지 않는다. 2026-09-27에 노출된 기존 키는 사용자가 폐기했으며, 실제 생성을 재개하려면 새 키와 새 접근 코드를 서버 환경 변수에 다시 설정해야 한다. 접근 코드는 공유된 사람에게만 전달하고, 사용량 상한은 OpenAI 프로젝트에서도 설정하는 편이 안전하다. 접근 코드만으로 사용자별 과금 한도를 강제할 수는 없다.

2026-09-28 배포 확인: 서버리스 모듈 경로 오류를 수정한 뒤 `GET /api/status`는 HTTP 200과 `available:false`를 반환했고, 과금 없는 `GET /api/generate`는 HTTP 405를 반환했다. 이는 함수 경로와 미설정 차단의 확인이며 실제 이미지 생성 성공 검증은 아니다. 최신 UI 변경을 배포한 뒤 같은 검사를 다시 수행한다.

타입 검사, 린트, 단위 테스트, 빌드는 유료 모델 호출 없이 수행한다. 라이브 OpenAI 이미지 편집 요청은 별도 유료 확인 전에는 실행하지 않았으므로, 실제 계정 결제·조직 인증·모델 접근 권한까지 성공했다고 주장하지 않는다. 계정 설정 문제나 API 실패 시 기존 결과와 무료 샘플은 유지된다.
