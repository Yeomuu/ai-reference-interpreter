## 실행한 검증

- 린트·타입 검사·빌드. 단위 테스트 112개/14파일 통과 (모델 응답은 mock).
- 기존 그리기 Chrome QA 19개: 두 구조/두 영역 연속 저장 후 도구 유지, 명시적 이동 탭 선택, 구조 이동, 연결 벽·스냅, 충돌 거절, Escape, 도구 전환, 1280/900/390px.
- 기존 레퍼런스/Keep Chrome QA 22개: 업로드·삭제·되돌리기·이력·보존 전환·직접 이동·수치 대안·좁은 화면. 새로고침은 현재 경로를 유지하므로 목록 재진입을 전제하던 QA를 갱신.
- 새 Chrome QA 7묶음: 이름+잠금, Back/Forward/새로고침, 동의 시작→Keep/조건 편집/취소→유효하지 않은 배치→복구→검토 수정 루프→새로고침→종료→6문항→실제 ZIP 다운로드. 1070/768/390px body overflow 없음. 참여 링크/키 입력 없이 직접 생성, 생성 중 다른 탭(서비스 단계) 왕복에도 버튼 잠금, 전체 상한 소진/서버 생성 중 차단·무료 샘플 유지, 새 프로젝트 경로와 프로젝트 간 Back/Forward 복구.
- 다운로드 ZIP은 Python `zipfile`로 12개 파일과 CRC 오류 없음, 한국어 CSV/설문 7행, 실제 이벤트·지표·완료 여부 확인. 가짜 정확도 점수 없음.
- 공유 상한 테스트: 여러 인스턴스 경쟁·완료 후 같은 요청 번호·전체 상한·한국 자정·중단 잠금 만료·오래된 해제·손상/증액 거절. API 입력 오류/상한/저장소 실패는 provider 호출 0, 유효한 요청은 mock 1회. 불확실한 결과도 예약 횟수 유지.

새 단위/브라우저 테스트, 문서화 후 최종 빌드 및 배포 검증 결과는 아래 배포 항목에 덧붙인다.

## 제한과 실험 준비 사항

- Google 문서 직접 접근은 불가. 첨부된 최신 14페이지 PDF의 마지막 5페이지와 관련 필드 정의를 실제로 읽었다.
- structured 조건 수집이다. 자유 텍스트 비교 방식·교차 배정·동등 A/B 자료·실제 정답 코딩·통계 검정은 구현/수행했다고 주장하지 않는다.
- 기록은 브라우저 한 탭 기준이며 ZIP을 직접 전달해야 한다. 서버 수집 시각은 null. 파일럿에서 제출 여부와 클라이언트 시계를 확인해야 한다.
- API 키는 서버에 존재한다는 상태만 확인한다. 이전 생성 키는 7일 만료 설정이며 실제 모델 권한/결제/생성 품질은 유료 요청을 실행하지 않아 미검증이다. 모든 QA 모델 호출은 mock 또는 호출 전 차단.
- 자동 승인 검토가 전역 상한 없이 인증을 제거하는 작업을 거부했다. 사용자가 전체 상한 후 직접 생성을 선택해 비공개 Blob을 실제 연결하고 초기화한 뒤 링크/코드 인증을 제거했다. 공개 사이트 사용자는 남은 공유 횟수를 사용할 수 있다. 횟수 상한이며 총 청구액 확정은 아니다.

- 실제 비공개 Blob의 별도 임시 QA 기록에서 같은 ETag로 경쟁 쓰기: 성공 1개, 다른 요청은 BlobPreconditionFailedError. 검증 후 임시 기록 삭제. 본 호출 상한은 사용 0회 그대로이고 모델 요청은 0회.
