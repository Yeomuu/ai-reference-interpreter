## 가이드·ZIP 산출물 확인

참여자 PDF 5쪽, 진행자/영상 PDF 6쪽을 1200px 이미지로 렌더링해 전 페이지 조합과 정보가 많은 본문·표 페이지를 확인했다. 실제 제공 Paperlogy를 로컬에서 사용했으며 TTF 파일을 산출물/배포에 복사하지 않았다. 공개 guide는 참여자 안내만 포함한다.
실제 브라우저 PDF 내려받기 성공. A 종료 → B 시작 → 재접속 → B 종료 → 6문항 응답 → B ZIP 내려받기 수행. ZIP CRC 정상, 12개 파일, task_set=B, condition=structured, 설문 6개 값 및 서버 시각 null 확인. 원본 이미지·API 키를 ZIP에 넣지 않았다.
영상 구성은 2분 10초·9장면의 촬영 순서/전달 내용과 내레이션·녹화 체크리스트다. 영상 파일을 제작했다고 주장하지 않는다.

## 남아 있는 검증 경계

1. 현재 앱은 구조화 인터페이스다. 자유 텍스트 비교 화면, 동등한 A/B 자료 패키지, 자동 교차 배정·서버 실험 로그 수집·자동 정확도 코딩은 미구현이다. A/B 태그만 바꾸면 비교 실험이 완성되는 것이 아니다. 사용성 파일럿에는 현재 기능을 사용할 수 있다.
2. 이전 승인된 실제 생성 2장의 창 위치·기둥 단면·전체 온색 문제는 품질 통과가 아니었다. 마지막 프롬프트 보완 후 실제 재생성 검증은 하지 않았다. 기능 QA 성공을 도면과 AI 이미지의 완전 일치로 표현하지 않는다. 상세 근거는 QA_PLAN_GUIDE_20260929.md.
3. 업로드 평면도를 자동 측정·자동 벡터화하는 CAD는 구현하지 않았다. 업로드를 배경으로 사용자가 구조/윤곽을 표시하는 방식이며 개략 도면의 정확한 실측을 주장하지 않는다.
4. 익명 일일 한도는 브라우저 쿠키 단위다. 동일 사람의 다른 기기/브라우저를 식별하지 않는다. Vite는 단일 JS 청크 500 kB 초과 권고를 출력하지만 빌드는 성공한다.
