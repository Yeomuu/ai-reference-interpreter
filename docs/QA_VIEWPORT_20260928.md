# 화면 고정·알림 배치 QA · 2026-09-28

## 변경 범위

- 알림·오류·삭제 되돌리기 안내를 메인 화면의 absolute 레이어로 옮겼다. 단계 이동 버튼을 가리지 않도록 하단 보조 영역 위에 표시한다. 일반 알림의 3초 후 페이드·즉시 닫기와 오류·되돌리기의 지속성은 유지한다.
- 앱을 100vw / 100dvh(100vh 대체)로 고정하고 document overflow를 숨겼다. 데스크톱은 긴 목록·속성·검토·결과 패널이, 1000px 미만은 활성 작업 영역이 내부 스크롤을 가진다. 작은 화면에서 입력·내보내기가 사라지지 않게 하기 위한 예외다.
- 프로젝트 기본 정보와 선택적 실험 기록은 작업 위치를 밀지 않는 펼치기 패널로 표시한다. 레퍼런스 메모·결과 이력·승인 모음은 사용자가 펼친다. 도면 출처와 측정 한계는 기존 상태 표시와 출처 안내로 보존한다.
- SVG의 부모 높이 계산을 분리하여 낮은 화면에서 도구·안내가 겹치는 문제를 수정했다. 레퍼런스 선택 상태 행의 높이를 확보하여 드래그 중 이미지 크기가 바뀌는 문제도 수정했다.

## 검증 한계

모든 콘텐츠에서 스크롤 자체를 제거하지는 않는다. 긴 목록, 확장된 상세 설정과 작은 화면의 작업 영역은 내부 스크롤로 접근한다. 문서·전체 페이지와 단계 이동 영역은 고정된다. 공개 배포 검증은 실제 배포가 Ready가 된 뒤 별도 기록하며, 이 문서는 로컬 구현·검사의 기록이다.
