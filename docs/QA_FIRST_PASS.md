현재 웹 앱을 로컬 `docs/`의 기능·QA 기준, [Google Doc 최신 §17–20](https://docs.google.com/document/d/1ACvyr2W8FkFqxCOeUUGbDniS8gvQctPcwj4BFovNLSw/edit?tab=t.c55ooetxpp14), [Figma 와이어프레임](https://www.figma.com/design/J2ZHftzWmLR7OQhpyMFJQA/?node-id=107-2), [디자인 시스템](https://www.figma.com/design/J2ZHftzWmLR7OQhpyMFJQA/?node-id=111-2)과 대조했습니다. 참고 대화는 기획 경위 자료로만 사용했습니다. 최종 방향인 기존 공간 기반 팝업스토어, 사진·도면 역할 분리, Keep, 유형별 배치, 시점·결과 검토와 지도 제외는 현재 흐름에 반영되어 있습니다.

`npm run lint`, `npm run typecheck`, `npm run test`(19개 통과), `npm run build`가 통과했습니다. 브라우저에서는 1440×900, 1280×800, 390×844에서 화면을 확인했고, 가로 넘침과 콘솔 경고·오류는 발견하지 못했습니다. 샘플과 신규 프로젝트에서 업로드, 구조 등록, 배치 충돌, 시점 검토, 결과 이력·내보내기를 조작했습니다.

## 이번 QA에서 수정한 오류

| 문제 | 수정·확인 |
|---|---|
| 무효한 추가 카메라를 골라도 검토 화면이 준비 완료로 표시됨 | 선택한 카메라도 사전 검증합니다. 바닥 밖 추가 시점은 미리보기 버튼이 비활성화되고 대표 시점으로 바꾸면 다시 활성화됩니다. |
| 새 평면도에 이전 구조·Keep·배치 좌표가 자동으로 유효한 것처럼 남음 | 업로드한 도면에는 임의의 사용 바닥을 만들지 않습니다. 사용 바닥을 직접 표시하고 도면 대응을 확인하기 전에는 미리보기를 차단합니다. 교체 시 기존 좌표는 검토용으로 유지합니다. |
| 벽에서 떨어진 창·문·출입구가 벽 개구부로 저장됨 | 연결 벽 선택과 벽 선 위의 서로 다른 두 좌표를 요구합니다. 브라우저에서 벽 밖 창 좌표가 거절되는 것을 확인했습니다. |
| 추가한 문의 여닫이 영역이 항상 도면 위쪽으로 잡힘 | 연결 벽의 방향과 바닥 중심으로 실내 쪽 여유 영역을 계산합니다. 상단 벽에 추가한 문 앞 진열대가 거절되는 것을 확인했습니다. |
| 회전한 가구의 충돌·도면 표시 불일치와 원형 기둥 누락 | 회전 후 점유 범위로 충돌을 검사하고 SVG 표시도 회전시켰습니다. 바닥 영역 지정 시 원형 기둥도 검사합니다. |
| 이미지 업로드 중 다른 수정이나 프로젝트 전환으로 이전 상태가 덮임 | 업로드 완료 시 최신 프로젝트 상태에 병합하고, 프로젝트가 바뀌었으면 자산을 정리하며 등록을 중단합니다. |
| 저장 실패 후 성공 안내와 자동 저장 문구가 남음 | 저장 성공 뒤에만 화면 상태와 성공 안내를 갱신하고, 실패 시 저장 오류를 표시합니다. |

## 아직 남은 기능과 검증 한계

- 이미지 생성 API가 연결되지 않았습니다. 결과는 현재 조건이나 추가 시점을 반영하지 않는 고정 AURA POP-UP 샘플이며, 화면에 이 사실을 표시합니다.
- 레퍼런스 화면은 이미지 역할 분리와 수동 요소 등록을 제공하지만, [제품 흐름](PRODUCT.md)의 이미지 전체 분위기 적용·제외 및 이미지 내부 영역/객체 선택은 아직 없습니다. 사진 Keep은 구조물의 대략적인 점 마커이며 영역 경계 선택은 없습니다.
- 승인 이미지 모아보기는 갤러리입니다. 무드보드 이미지 다운로드와 여러 결과·배치도·설정을 묶은 ZIP은 아직 없습니다. ZIP 등 고급 내보내기는 최신 기획 문서의 확장 범위로 구분됩니다.
- 업로드 도면의 바닥은 사용자가 사각형 영역으로 표시합니다. 도면 치수·구조 자동 인식과 불규칙한 바닥 윤곽, 실제 문 여닫이 방향의 측량은 제공하지 않습니다. 문의 여유 영역은 평면도에서 추정하므로 현장 조건을 사용자가 확인해야 합니다.
- 공식 [Nucleo 무료 UI Essential](https://nucleoapp.com/free-ui-icons)의 Outline SVG는 선택 가능한 출처로 확인했지만, 실제 사용할 아이콘 SVG와 이름·라이선스 매핑은 아직 확보하지 않았습니다. [AI Integration](https://nucleoapp.com/ai-integration)은 Codex용 설치 경로를 안내하나 현재 세션에 설치되지 않았고 무료 설치 목록에 UI Essential이 명시되어 있지 않습니다. 따라서 현재 조작부는 텍스트로 유지합니다. 자세한 확인 상태는 [ICON_MANIFEST.md](ICON_MANIFEST.md)에 있습니다.
- Paperlogy v1.001은 제작자 공식 배포본과 해시가 일치하여 적용했습니다. 근거는 [FONT_PROVENANCE.md](FONT_PROVENANCE.md)에 있습니다.

이번 검사는 1차 QA입니다. 실제 생성 API, 실측 도면, 다양한 브라우저·운영체제의 통합 검증은 연결 후 별도로 필요합니다.
