# 적용 위치 연결·영역 가시성 QA · 2026-09-29

## 이번 변경

- 참고 이미지에서 요소 등록 시 전체 공간/실제 영역을 지정하고 선택한 요소의 위치를 바로 수정한다. 배치의 동일한 선택기와 영역 목록/이름표도 같은 target을 저장한다.
- 조명 분위기는 전체 공간·공간/바닥 영역, 천장 등기구는 천장 영역을 사용한다. 벽/스탠드 조명의 기존 typed 위치 도구는 유지한다. 이미지 크롭은 공간 적용 범위와 별도다.
- 기본 영역 이름은 선택한 하나만 표시한다. 다른 영역 흐리기, 종류별 표시, 이름표 전체 표시와 실제 이름 목록을 제공한다. 표시 옵션은 공통 조건을 수정하지 않는다.
- 짧은/좁은 공간 준비에서 도면을 작은 스크롤 구간에 가두던 문제와 표시 팝업 잘림을 수정했다. 앱 바깥은 스크롤하지 않는다.

## 검증 범위와 제한

- 이미지 생성 POST는 모의 이미지 응답 또는 차단으로 검사했다. 실제 유료 모델 호출은 0회이며, 특정 조명 범위가 생성 이미지에 정확하게 재현되는 품질을 이번 QA로 보장하지 않는다.
- 데이터 검사는 위치 연결의 직렬화, 기존 조건 snapshot, 생성 프롬프트의 실제 영역 이름까지 포함한다. 자동 구조 추출·실측·CAD 기능은 추가하지 않았다.
- 이름표 공간이 부족하면 일부 이름표를 접는다. 전체 이름과 선택 기능은 영역 목록에 남는다. 표시 옵션은 저장 대상이 아니며 새로고침 시 기본 보기로 복귀한다.
- 캡처·브라우저 스크립트·상세 JSON 보고서는 Git/배포에서 제외된 `qa-screens/`에 보관한다. 유료 호출 또는 비밀 값은 보고서에 포함하지 않는다.
