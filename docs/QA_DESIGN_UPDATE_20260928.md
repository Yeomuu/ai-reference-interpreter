## MD 규칙 병합

- `DESIGN_SYSTEM.md`는 첨부 v1.2로 갱신했다. 구현한 레이아웃·상태 토큰은 18절에 근거와 함께 명시했다.
- 첨부 문서와 예시의 Keep 번호·녹색 halo·사용자 접근 코드 규칙은 현재 제품 계약에 맞춰 **실제 이름+잠금 아이콘**, **코드 없는 서버 env 생성+공유 상한**으로 수정했다. 고정 구조의 이동 금지는 보존을 켠 동안 적용하며, 사용자가 해제한 상태를 되돌리지 않는다.
- Figma 최종 v1.3의 좌측 탐색을 적용하면서 첨부의 이전 가로 탐색 규칙을 데스크톱 좌측/좁은 화면 가로로 명확히 했다.
- `DESIGN_REFERENCE_SYNTHESIS.md`를 추가했고 `AGENTS.md`의 현재 실행 계약을 보존한 채 참고 디자인의 사용 범위를 병합했다.
- `PRODUCT`, `INTERACTIONS`, `ARCHITECTURE`, `QA`, `UX_SPEC_CHANGELOG`도 실제 화면 이름·패널·검증 기준과 동기화했다. 기존 변경 이력은 삭제하지 않았다.

검증 화면은 1440×900, 1280×800, 768×900, 390×844다. 추가 기능 QA에는 1070px·900px도 포함한다. 가로 본문 넘침과 브라우저 실행 오류는 발견되지 않았다. 1440×900에서 배치·시점 도면 표면은 높이 460px, 하단 800px이며 중앙 패널은 작업 영역의 53.5%다. 1280×800에서도 초기 도면 표면이 화면 안에 들어온다. 태블릿에서는 도면 아래 두 패널이 같은 행을 쓰고, 휴대폰에서는 순서대로 이어진다.

브라우저 검증은 별도 테스트 저장소와 샘플 자산을 사용했다. 실제 유료 모델 호출은 **0회**이며, 생성 중 잠금 검증 1회는 모의 응답이다. 새 이미지 모델 실행·생성 결과 정확도 검증을 수행했다고 주장하지 않는다. 프로덕션 폰트는 기존 정책대로 대체 폰트이며 사용자 Paperlogy 바이너리는 포함하지 않는다.

## 범위와 검증 산출물

- 신규 API·라이브러리·아이콘·데이터 모델·연구 기능은 추가하지 않았다. 서버 API 키와 전체 60회/하루 20회 상한 계약도 유지한다.

- 실제 사용자 사용성 실험과 생성 이미지의 조건 충족 평가, 미구현 자유 텍스트 비교는 이번 디자인 QA와 별개다.
