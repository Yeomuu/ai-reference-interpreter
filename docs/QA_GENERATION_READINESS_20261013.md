# 생성 조건과 완료 상태 검증 · 2026-10-13

사용자 제공 실험 ZIP에서 배치 물체 20개와 mapping-condition 2개를 복원했다. 도면, 가벽 A/B 면, 벽면 span, 상품 받침 관계, crop, 분위기 연결, 입구 카메라를 유지했다. ZIP에는 이미지 픽셀이 없으므로 사용자가 확인한 다운로드의 p02.jpg와 grad-wall-washer.png를 별도 비공개 검증 저장소에 복원했다. 기본 제공 전시대·조명 이미지와 프로젝트룸 사진을 사용했다. 사용자 Chrome 저장소를 직접 읽었다고 주장하지 않으며 원본 프로젝트를 덮어쓰지 않았다. 원본 실험 기록·사진·조건 본문은 Git에 포함하지 않는다.

## 원인과 수정

- 이 조건의 공간 preflight는 valid였으나 반복 지침을 포함한 prompt가 기존 앱 상한 16,000자를 초과했다. 완료 상태는 이미지/prompt 준비를 확인하지 않고 공간 preflight만 사용했다.
- 앱 상한은 제거하고 실제 Images edits API의 32,000자 입력 용량을 공유한다. 긴 요청은 공통 설명을 공유하며 필요한 경우 키 기반 JSON을 사용한다. 개별 조건 문장은 잘라내지 않는다. 구조 100개 거절과 4개 crop 거절도 제거했다. 20개 물체, 보존/충돌, 유료 quota/replay 계약은 유지했다.
- 상태 창·버튼·클릭은 같은 readiness를 사용한다. 실제 이미지 읽기·압축·시점별 도면·prompt·본문 검사를 완료해 보관한 요청을 전송한다. 조건 변경/원본 누락/서버·quota 확인 실패/저장 오류/불확실 요청은 초록 표시가 되지 않는다.

## 검증

- 앱/API TypeScript, ESLint, production build 통과. 35개 테스트 파일의 305개 테스트 통과. JSON 축약의 개별 문장/좌표/카메라 보존, 다수 영역, crop 4개 초과, 준비 실패와 quota/replay 회귀 포함.
- 격리 Edge/Playwright에서 복원한 조건 22개, 입구 시점, 입력 이미지 4개, 본문 1,250,035바이트의 실제 클라이언트 준비와 POST 1건을 확인했다. 생성 API 응답은 mock이며 이 검증은 유료 모델 실행을 뜻하지 않는다.
- 완료 상태/활성 버튼 → 클릭 → 생성 중 중립 상태 → 결과 저장/결과 탭 흐름 확인. quota 0과 적용한 원본 이미지 누락은 완료 표시와 버튼을 함께 차단했다. JavaScript 오류 없음.
- 1440×900, 938×672 화면을 캡처하고 직접 확인했다. 증거는 작업의 외부 시각화 폴더 generation-readiness-20261013에 보관했다.
- 실제 모델 생성과 운영 배포 확인은 배포 후 추가 기록한다. 네트워크·외부 모델 장애까지 생성 성공을 보장하는 표시는 아니다.
