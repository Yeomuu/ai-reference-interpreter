# 중간 영상 피드백 반영

## 확인한 근거

- 사용자 제공 `프로토타입 중간 검토.mp4`: 3분 8.90초, 1920×1080. 10초 간격 19프레임과 현재 앱의 격리 브라우저 화면을 확인. 오디오 내용은 분석하지 않음.
- 약 15–65초: 공간 구조·영역 편집에 여러 도구와 설명이 동시에 등장. 기본 사용에도 모든 도면 편집이 필요한 인상을 줌.
- 약 105–125초: 참고 이미지 등록과 공간 배치를 오가며 조작. 현재 화면에는 위치 연결/위치 편집의 중복과 5개 편집 동작이 항상 노출됨.
- 약 155–175초: 가상 AURA 샘플에서 생성 결과로 넘어가 실제 장소와 연결이 약함.
- 사용자 선택 이름: **Scene Edit · 전시·팝업 공간 디자인**. 상표·도메인 사용 가능성을 인증한 이름은 아님.

## 수정

1. 기존 7개 URL/기록 단계는 유지하고 연구 목적의 4개 작업 묶음으로 안내: 공간 확인(공간 준비·Keep) / 참고 요소 선택(Reference) / 공간 배치·시점 지정(Location·Viewpoint) / AI 시안 확인·수정(Review·Results). 현재 묶음의 세부 작업만 펼친다. Keep은 필요할 때 열며 이미 등록된 보존 상태를 바꾸지 않는다. 공간 준비의 다음 버튼은 참고 이미지로 간다.
2. 참고 이미지에서 ‘추가하고 배치하기’로 명시적으로 등록과 다음 행동을 연결. 기존 ‘요소 추가’는 현재 화면을 유지. 편집·제외·삭제는 펼쳐 사용하고 중복 위치 편집 버튼은 제거.
3. 창은 이중선, 출입구는 빈 개구부와 문설주, 문은 사용자가 지정한 경우 문짝과 회전 호. 미지정 방향은 추정하지 않는다. 벽·기둥·등은 기존 저장 geometry를 사용한다. 편집 화면과 생성 입력 도면이 같은 기하 함수를 쓴다.
4. 한국공학대학교 디자인공학부 프로젝트룸의 공식 사진에서 시작하는 졸업전시/가상 브랜드 팝업 예시. 동일한 개략 도면을 사용한다. 졸업전시를 시작 화면의 기본 예시로 두고 팝업·AURA는 보조로 둔다. AURA 가상 실내 사진을 학교로 바꾸어 부르지 않는다. 학교 사례의 AI 결과는 미리 넣지 않는다.

## 사진 출처와 가정

[학교 공식 학부실습실 안내](https://www.tukorea.ac.kr/design/1999/subview.do)의 **프로젝트룸** 섹션에 있는 사진을 확인했다. 정확한 건물·호실은 해당 페이지에서 확인되지 않아 표기하지 않는다. 별도 [NO:DE 학술대회 게시물](https://www.tukorea.ac.kr/bbs/design/244/147872/artclView.do)은 A동 4층 행사라는 근거지만 프로젝트룸의 위치 근거로 쓰지 않는다.

- 화이트보드·출입문 사진: `https://www.tukorea.ac.kr/CrossEditor/binary/images/000204/20250227110344480_U1FT67XC.jpg`
- 창 쪽 사진: `https://www.tukorea.ac.kr/CrossEditor/binary/images/000204/20250227110236997_UUES23ON.jpg`
- 다른 각도 확인 자료: `https://www.tukorea.ac.kr/CrossEditor/binary/images/000204/20250227110417995_SDGS0HHV.jpg`
- 사진 제공/권리: 한국공학대학교. 공개 열람 가능하며 별도의 자유 이용 라이선스는 확인하지 못했다. 원본 그대로 출처와 함께 교육 목적 기획 예시에 사용. 별도 외부 홍보물로 재배포 시 사진 이용 조건 확인 또는 직접 촬영본으로 교체.
- 사진의 촬영일·현재 상태, 실제 치수, 전체 창/문 수, 반대쪽 구조는 확인되지 않았다. 개략 도면은 설명용 수작업 가정이다. 보이지 않는 뒤쪽 벽과 출입문 범위도 가정으로 명명한다. 기존 책상·의자의 이동, 학교 사용 허가, 실제 전시는 확정 사항이 아니다.

## 기호 근거와 한계

사용자 첨부 기호표와 [Autodesk의 문 표시 요소 설명](https://help.autodesk.com/cloudhelp/2025/ENU/AutoCAD-Architecture/files/GUID-3B0C4A84-DCF1-4369-8BCE-65646270A74C.htm)을 참고. 일반적인 평면 표현을 실제 선분 좌표로 그린다. 특정 KS/ISO 제도 표준 준수나 시공 도면으로 인증하지 않는다. 문 기호 방향은 표현 정보이며 실제 충돌 검사는 별도로 등록된 clearance를 사용한다.

## 영상 방향

[별도 90초 촬영 구성안](SCENE_EDIT_VIDEO_FLOW.md)은 기능 목록 나열보다 ‘실제 공간 + 바꾸고 싶은 점 + 유지할 것 + 결과 대조’를 중심으로 한다. 기존 실험 A/B 자료 과업 정의를 학교 시나리오로 몰래 바꾸지 않는다.

## 졸업전시 참고 이미지

`public/sample/campus/exhibition-display.png`와 `exhibition-lighting.png`는 2026-09-30에 이미지 생성 도구로 만든 **기획 참고 이미지**다. 한국공학대학교의 실내 사진이나 이 서비스가 생성한 최종 시안으로 취급하지 않는다. 졸업전시 예시에서 기존 팝업스토어 상품·매장 이미지를 대신하며, 공간의 실제 구조·치수에 대한 근거로 사용하지 않는다.
