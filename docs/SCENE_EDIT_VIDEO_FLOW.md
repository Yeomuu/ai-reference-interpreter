# Scene Edit 소개영상 촬영 구성 · 한국공학대학교 프로젝트룸

## 핵심 상황

한국공학대학교의 한 학생이 디자인공학부 **프로젝트룸**을 졸업전시 공간으로 사용할 수 있을지 구상한다. 학교 [공식 학부실습실 안내](https://www.tukorea.ac.kr/design/1999/subview.do)에 있는 실제 사진을 출발점으로 삼는다. 공간 사용 허가, 현재 실내 상태, 실제 치수는 확인되지 않았다. 영상 전체에서 **제안된 전시 시안**으로 표기하고, 실제로 개최된 전시처럼 표현하지 않는다.

기존 A/B 논문 과업은 별도 자료 묶음이다. 이 영상은 서비스 사용법을 보여주는 **연습 시나리오**이며 A/B의 실험 답안을 대체하지 않는다.

## 90초 화면 녹화안

| 시간 | 화면·사용 행동 | 말/자막의 요지 |
|---|---|---|
| 0–8초 | 학교 공식 프로젝트룸 사진 전체를 보여주고 출처를 표시 | “학교 프로젝트룸을 졸업전시로 꾸며 본다면?” |
| 8–22초 | Scene Edit의 ‘졸업전시 구상 시작’ → 공간·방향 설정. 실제 사진/개략 도면과 유지 구조를 확인 | “먼저 실제 공간을 봅니다. 창·출입문·화이트보드 쪽 벽은 지킬 조건으로 확인합니다. 도면은 설명용 가정이며 치수는 미확인입니다.” |
| 22–38초 | 레이아웃 구성. 전시대 4개·테이블·의자·조명·공간 영역을 먼저 배치 | “참고 이미지를 고르기 전에 공간 레이아웃을 먼저 구성합니다.” |
| 38–56초 | 레퍼런스 적용: 선택한 이미지 영역을 전시대 1·2·4에 한 번에 연결하고 벽·영역에 적용 | “필요한 디자인만 이미 놓인 요소에 연결합니다.” |
| 56–70초 | 시안 생성에서 카메라 위치·방향과 조건을 확인하고 실제 이미지 **1장** 생성 버튼을 클릭. 결과 화면까지 컷 편집 | “실제 사진·유지 조건·배치·시점을 묶어 시안을 확인합니다.” 생성 중 경과는 가짜 퍼센트로 표현하지 않는다. |
| 70–83초 | 실제 사진, 당시 저장 도면, 생성된 이미지 대조. 결과가 다르면 해당 요소/위치로 돌아가 한 항목만 수정 | “사진과 도면을 기준으로 맞는지 직접 비교합니다. 마음에 들지 않는 부분만 수정할 수 있습니다.” |
| 83–90초 | 결과 화면과 서비스명 | “Scene Edit · 전시·팝업 공간 디자인” |

## 촬영 전 확인

- 실제 이미지 생성 결과를 보여주려면 **학교 공간으로 실제 모델을 실행하고** 그때 저장된 결과를 사용한다. 샘플 AURA 이미지를 학교 사례의 생성 결과로 편집하지 않는다.
- 사진의 현재성·공간 사용 가능성·개략 도면과 실제 구조의 일치 여부를 자막에서 과장하지 않는다. ‘사진 참고 개략 도면’ 표기를 화면에서 읽을 수 있게 둔다.
- 촬영용 브라우저의 연구 참가자 기록을 켜지 않는다. 개인정보·API 키·접근 코드·결과 요금은 노출하지 않는다.
- 학교 사진을 외부 배포 영상에 넣기 전에 이용 조건을 확인한다. 이용 조건이 허용되지 않으면 해당 공간의 직접 촬영본으로 교체한다.
- 브랜드 팝업 예시는 영상의 본편에 섞지 않는다. 필요할 때 같은 도면으로 다른 목표를 구상할 수 있음을 엔드카드의 한 문장으로 소개한다.
